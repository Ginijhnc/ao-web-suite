# AOWeb Suite

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A cross-platform texture atlas indexer and game data editor for [Argentum Online](https://web.archive.org/web/20090925051554/http://www.alkon.com.ar/foro/argentum-online.53).

## Overview

AOWeb Suite is designed to work with JSON-based asset management typical from [Argentum Online Web](https://github.com/horacioMartinez/dakara-client) forks. The project is inspired by the classic [Destruction-AO Index-Dater (Visual Basic 6)](https://www.youtube.com/watch?v=GoqAC9eRk04) from 2009, so that users familiar with the original tool can transition without too much friction. It also doesn't have the ever-increasing compatibility issues that come with legacy VB6 software, its OCX controls, and runtime DLLs.
